# Changelog

## 0.5.0-beta.2

- Rename the product to Memory System V2 and npm package to `memory-system-v2`.
- Publish the package and add tested English/Chinese installation examples.
- Simplify public documentation and make installation and downloads easier to find.
- No changes to memory behavior or storage format.

## 0.5.0-beta.1

- Add the LongMemory-based chat SDK, exact message storage and source-backed recall.
- Add explicit corrections, historical recall, deletion, restart recovery and rebuilding.
- Add tests and a synthetic benchmark using real embeddings.

Older versions are available under [GitHub releases](https://github.com/ziningshu-code/memory-system-mvp/releases). They have different package names and data formats; use the instructions included with the version you install.
