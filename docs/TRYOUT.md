# First use

Use the [installation guide](./PLUGIN.md), then keep using your normal Codex conversation.

To check that capture and retrieval work, state a harmless fictional identifier in one session, close it, and ask for that identifier in a new session in the same project. Do not put the answer in the second question. Inspect the actual memory tool result and its original source.

That checks cross-session integration. It does not measure a model's context limit or prove a general accuracy improvement.

The previous scripted walkthrough is legacy material, not the current setup or a real-model result. See [evaluation status and earlier results](./EVALUATION.md).
