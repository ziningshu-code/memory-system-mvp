# Using older versions

The [V1 release](https://github.com/ziningshu-code/memory-system-mvp/releases/tag/legacy-v1) has its own code and instructions. It uses a different package and storage format from Memory System V2.

V1 data is not imported automatically. Keep the original files and use the version that created them. For the current SDK, follow the [installation guide](../README.md#install).
