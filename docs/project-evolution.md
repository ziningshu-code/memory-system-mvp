# Version compatibility

The current package is `memory-system-v2@0.5.0-beta.2`. It uses the same memory runtime and database format as beta.1. Existing database paths keep their original directory name.

[Beta.1](https://github.com/ziningshu-code/memory-system-mvp/releases/tag/v0.5.0-beta.1) used the package name `memory-system-mvp`. Its download and tagged instructions are available on that release page.

[V1](https://github.com/ziningshu-code/memory-system-mvp/releases/tag/legacy-v1) used a different memory engine and file format. There is no automatic import into V2. Keep a copy of old data and use the matching version to read it.
